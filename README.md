# 🌵 Cactus - Landing Page

Uma landing page responsiva, elegante e moderna desenvolvida para uma loja de plantas ornamentais (focada em cactos e suculentas). Este projeto destaca o uso de HTML semântico, CSS avançado e animações dinâmicas de rolagem.

Nota: Este projeto faz parte do meu portfólio de estudos fundamentais de desenvolvimento Web.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica para SEO e acessibilidade.
- **CSS3**: Layouts baseados em CSS Grid e Flexbox, além de variáveis CSS para fácil manutenção.
- **JavaScript**: Utilizado para criar interatividade e animações dinâmicas.
- **ScrollReveal JS**: Biblioteca para criar animações de revelação conforme o usuário interage com a página.
- **Remix Icons**: Biblioteca de ícones vetoriais para uma interface limpa.

---

## 🧠 Aprendizados e Evolução

Ao desenvolver este projeto, foquei em consolidar conceitos essenciais de Front-end:

- Manipulação de DOM: Implementação de um menu mobile funcional (abrir/fechar) e um botão "Scroll Up" utilizando JavaScript puro.

- Integração de Bibliotecas Externas: Configuração e personalização da biblioteca ScrollReveal para criar uma experiência de usuário (UX) mais fluida e dinâmica, sem comprometer a performance.

- Design Responsivo (Mobile-First): Aplicação de técnicas de design adaptativo para garantir que a vitrine de produtos e as informações de contato sejam legíveis em qualquer tamanho de tela.

- Semântica e SEO: Uso correto de tags dando sentido semântico para o conteudo, facilitando a leitura por motores de busca.

- Organização de pastas: Estruturação profissional de pastas (assets/img, assets/css, assets/js), prática essencial para projetos escaláveis.
